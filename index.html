雲端資料庫連線設定（Firebase 跨裝置即時同步）

📌 Firebase 免費申請 4 步驟（設定一次即可讓所有委員手機免設定自動連線）：
  1. 前往 Firebase Console 建立免費專案，進入左側 Build > Authentication 啟用「匿名（Anonymous）」登入。
  2. 進入左側 Build > Firestore Database 建立資料庫（選擇「測試模式」啟動，或於規則中開放 allow read, write: if request.auth != null;）。
  3. 點擊左上角齒輪 專案設定 > 您的應用程式 > 網頁 (</>)，註冊應用程式後複製 firebaseConfig 大括號內的 JSON 設定貼入下方。
  4. 儲存連線後，只要點選「複製帶雲端設定的委員投票連結」傳給委員，委員手機點開即自動連上同一雲端會議室，無需任何設定！

如何讓委員手機連上線？

⚠️ 目前偵測到您正在「預覽沙盒視窗」中操作：

預覽環境產生的臨時網址（blob:）僅限您目前這台電腦的瀏覽器檢視，委員從外部手機或電腦點擊會顯示無法連線。

只需極簡 3 步驟，免費取得正式公開網址並分享給全體委員：
1
下載完整單頁網頁檔：點擊下方綠色按鈕，將本系統下載為 index.html 檔案。
2
免費拖曳上線（免寫程式）：開啟 Netlify Drop（或上傳至 GitHub Pages），將下載的 index.html 拖曳進去，3 秒即可獲得正式 https://... 網址。
3
複製正式投票連結給委員：開啟您的正式 https:// 網址後，再點擊「複製委員投票連結」（系統會自動將房間碼與雲端設定編碼進連結），貼至 LINE 群組即可讓委員手機免設定直接投票！
